# 妙妙的喂饭日历

公开网站仅包含页面、日历图片和字体。个人喂食、体重及勾选记录保存在 `QuinnPeter/miaomiao-data` 私有仓库。

网站通过 GitHub Contents API 读写私有数据。每次保存以最新文件 SHA 为条件提交，冲突时重新读取并合并本次操作；唯一操作编号用于防止重试重复累计。

## 连接

在 GitHub 创建细粒度个人令牌，仅授权 `miaomiao-data` 仓库的 Contents Read and write 权限。在网页输入令牌。不要将令牌提交到任何仓库。

默认仅在当前会话保存授权；可选择在私人设备保持连接。退出会清除当前浏览器中的记录缓存和授权。令牌过期后需要更新授权。

## 维护

Pages 使用本仓库 `main` 分支根目录。只上传网页文件；不要上传数据库、记录 JSON、浏览器缓存、迁移备份或任何授权令牌。

日历月份：2026 年 9 月。日期按上海时间。体重未填写时从初始 3.60 kg 或此前记录推算，未来日期不显示体重。

字体许可见 `字体许可.txt`。
